# ゴール2：Webアプリ（参加者向け・スタッフ用ダッシュボード）

docs/spec.md の4章と7章に従い、web/ に TypeScript + React + Vite で実装する。見た目は docs/design.md に従う。API は server/ のものを使い、型は shared/ から参照する。

## 完了条件

ビルド・型チェック・テストが全て通ること。

### 参加者向け

- 4-1 の全画面がある（初回説明、電子スタンプ帳、QR表示、押印演出、ゴールページ、スポット地図・一覧、協賛企業）。ヘッダーのタブで電子スタンプ帳・マップ・協賛企業を切り替えられる
- 初回説明画面に「スタンプはこのブラウザに保存されます。別のアプリやブラウザで開くと最初からになります」を表示する
- スタンプ帳の「遊び方」「景品交換所の案内」「スタンプが消えた方へ」は、押すとポップアップで説明が開く
- ゴールページへは、完走後にスタンプ帳中央のGOALから開ける
- QR表示画面は /api/me のトークンを 75×75 CSSピクセル・誤り訂正レベルMで描き、表示中は Screen Wake Lock で画面消灯を抑止する
- 4-4 の4つの反映経路（SSE自動再接続、再接続時の再取得、visibilitychange 時の再取得、10秒ポーリング）がすべて実装され、テストで確認されている
- 押印の受信（SSEと10秒ポーリング）はアプリの最上位で持ち、どのタブにいても押印演出が出る
- 同じ押印イベントを複数回受け取っても演出は1回だけで、ACK は返す
- 5個目の押印でゴールページへ自動遷移する
- 日本語と英語を切り替えられ、初期表示はブラウザの言語設定で決まる
- Google Maps の API キーは環境変数から読み、キーが無ければリストだけで動く
- スタンプ絵柄と協賛企業の情報は仮のデータでよい。差し替え方法を README に書く

### デザイン

- docs/design.md 2章のトークンを web/src/styles/tokens.css に定義し、色・枠線・影・角丸・フォントはこの変数だけを使う。tokens.css 以外に色コードの直書きが無いことを、テストかlintで確認する
- docs/design.md 3章のコンポーネントを web/src/components/ui/ に実装する
- スタンプ帳は 4-1 の輪の配置（中央にGOAL、5つの枠を真上から時計回りに72°ずつ）で描く
- タップできる要素は押すと影のぶん沈む。prefers-reduced-motion では動きを止める
- 開発時だけ表示される /dev/gallery に、全コンポーネントを全状態で並べる
- 4章の各画面を、日本語と英語の両方について 390×844 で撮影したスクリーンショットを docs/screenshots/ に保存する（Playwright。APIはモックでよい）

### スタッフ用ダッシュボード（/admin）

- 7章の機器稼働状況と参加状況を表示し、30秒ごとに自動更新する
- 断になった機体と未送信キューが溜まった機体を画面上部に固定表示し、音またはブラウザ通知で知らせる
- 共有パスワードで保護する
- スマホで見やすいレイアウトにする
