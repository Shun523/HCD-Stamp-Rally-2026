# `design.md` 修正事項 — 台紙型スタンプ帳

この文書は、参加者向けの電子スタンプ帳を、円形のすごろくマップから「1枚のスタンプ台紙」へ変更するための修正事項をまとめたものである。`docs/design.md` 本体は変更せず、反映時の差分仕様として扱う。

先に作成した「見開き型スタンプ帳」の修正事項は破棄し、本書に置き換える。`OpenStampBook`、`BookStampSlot`、`GoalBookmark` は作らない。すでに実装済みであれば削除する。

## 1. 変更の目的

- 画面を見た瞬間に「スタンプ台紙に押して集める体験」だと伝わるようにする
- 押印欄を、押すためのUI部品ではなく、紙に印刷された押印欄として見せる
- ネオブルータリズムは「机に置かれた1枚のカード」という物体の表現に使い、台紙の内側は影のない印刷物として描く
- ゴールを、切り取り線で区切られた「景品引換券」として表し、紙の台紙の体験をそのまま画面に移す
- 円形の道、地面、木による「すごろくマップ」の印象をスタンプ帳画面から取り除く
- 回る順番は自由という仕様（spec Q-13）を、欄同士を線で結ばないことと案内文で伝える

## 2. `design.md` 0章「方向性」の修正

冒頭の方向性を次の内容へ差し替える。

- **レイアウト**は、縦長1枚のスタンプ台紙とする。上から、刷られた見出し、案内文、5つの押印欄、切り取り線、景品引換券の順に並べる
- 5つの押印欄は丸い点線の枠とし、上段に3つ、下段に2つを中央寄せで並べる
- 押印欄同士を道、線、矢印で結ばない。番号はスポットの識別にだけ使い、訪問順を表さない
- 太い枠線、ぼかしのない影は、台紙の外周と、台紙の外にあるタップできる部品（タブ、InfoTile、ボタン）に使う。台紙の内側に刷られた要素には影を付けない
- ネオブルータリズムの配色、太い丸ゴシックは維持する
- スタンプ帳画面では、緑の地面、黄土色の道、木の装飾を使わない

「ゴールページはスタンプ帳の中央のGOALから開く」は、次の内容へ変更する。

- **ゴールページ**は、完走後に景品引換券の「ゴールへ」ボタンから開く。5個目の押印時は従来どおり自動で遷移する

画面遷移図の `book -- 完走後のGOAL --> goal` は意味を維持し、入口の位置だけを輪の中央のメダリオンから景品引換券へ変更する。

## 3. デザイントークンの修正

次の3つを追加する。

```css
--color-paper: #FFFCF3;           /* 台紙の紙面。surface より少し温かい白 */
--color-watermark-line: #F1DAD4;  /* 押印欄の下絵の線 */
--color-watermark-fill: #F4E4DF;  /* 押印欄の下絵の塗り */
```

- 台紙の地は `--color-paper`、押印欄の円の内側は `--color-surface`、画面背景は `--color-bg` とする
- `--color-muted` の文字は `--color-paper` の上でも 7:1 以上を保つ
- 下絵は半透明で重ねず、上記の不透明な淡色で描く（1章原則3を維持する）

押印欄の点線は CSS の `border: dashed` ではなく SVG の円で描く。CSS の破線は円周上で間隔が不揃いになるため。

- 線の色 `--color-ink`、太さ2.5px、`stroke-dasharray: 3 5`

`--color-board`、`--color-road`、`--color-tree` はスタンプ帳画面では使わない。ゴールページの道の帯など、既存の別画面で必要な間は削除しない。

## 4. コンポーネントの修正

### 4-1. StampCardを追加

台紙全体を表すコンポーネントを追加する。

- 背景 `--color-paper`、外枠 `--border`、影 `--shadow-lg`、角丸 `--radius-card`
- 幅は `100%`、最大350px、`box-sizing: border-box`。右下の影8pxと左右の切り欠きを含めて、画面の左右余白の内側に収める
- 見出しは `<h2>` とし、全体に `aria-label`（例：「スタンプ台紙。5つのうち2つ押印済み」）を付ける

上から順に:

1. **刷られた見出し。** 左に「STAMP RALLY CARD」（12px / 900、`--color-coral-strong`、字間0.18em）と「スタンプ台紙」（display 22px）、右に「岡山大学／ホームカミングデー」（12px / 800、`--color-muted`、右揃え、2行）。下に2pxの実線
2. **案内文。** 「空いている丸をタップして、スタンプ機を押し当ててね。どの順番でもOK。」（12px / 800、`--color-muted`）。英語は「Tap an empty circle, then press the stamp machine on it. Any order is OK.」
3. **押印欄。** `CardStampSlot` を5つ、`flex-wrap` と中央寄せで並べ、上段3・下段2にする。列幅100px、列間・行間10px
4. **PrizeStub（景品引換券）。**

### 4-2. CardStampSlotを追加

台紙内だけで使う丸い押印欄を追加する。マップで使う円形の `SpotMarker` / `StampSlot`（影あり）とは分ける。

共通:

- 直径84pxの円。塗りは `--color-surface`、線は3章の点線
- 左上に、円から4px はみ出して番号バッジを置く（24px、`--color-purple`、白文字、`--border-thin`）。番号は訪問順ではなく識別番号である
- 円の下にスポット名（12px / 900）。最大2行まで折り返す
- DOM順とフォーカス順はスポット1〜5のデータ順とする
- 日本語・英語ともに、アクセシブルネームへスポット名と状態を含める

未押印:

- `<button>` とし、タップすると従来どおり全画面のQR表示を開く。タップ領域は円とスポット名を含む欄全体
- 円の中に下絵と「ここに／スタンプ」（12px / 800、`--color-muted`、2行、中央揃え）を置く
- 下絵は全スポット共通の図案（二重円と星）を `--color-watermark-line` と `--color-watermark-fill` で描く。スポット固有の絵柄は、押すまでの楽しみとして見せない
- 印刷物に見せるため、影を付けない。1章原則1「タップできる要素には影をつける」の例外とする
- 押下時は、沈む動きの代わりに円の内側を `--color-pink` で塗る。`focus-visible` は既存の共通ルールに従う

押印済み:

- 操作できない要素とし、影を付けない
- 点線の円は残し、紙面の押印位置であることを示す
- `StampImage` を円の約112%（94px）で重ね、枠からわずかにはみ出させる。スポットごとの既存の傾きを維持する
- 仮画像には、インクのかすれとして外周の輪と星の上に紙色（`--color-paper`）の小さな点を4〜5個置く。確定画像はかすれを含んだ絵柄で用意してもらう
- 番号バッジはスタンプ画像より前面に置く
- スタンプ画像は隣の押印欄に重ねない

### 4-3. PrizeStub（景品引換券）を追加し、GoalMedallionを置き換える

台紙の最下部に置く。

- 上端に3pxの破線（`--color-ink`）を引き、切り取り線とする
- 切り取り線の左端寄りに、はさみのアイコン（20px）を置く。背景を `--color-paper` にして破線を途切れさせる
- 切り取り線の左右の端に、直径24pxの切り欠きを置く。背景 `--color-bg`、枠 `--border`、`clip-path` で台紙の内側の半分だけを見せ、台紙の外枠を半円に切り欠いたように見せる
- はさみと切り欠きは装飾とし、`aria-hidden="true"` にする

未完走:

- 左に「景品引換券」（12px / 900、`--color-coral-strong`、字間0.14em）と「5つ集めたら、景品交換所でこの画面を見せてね」（13px / 800）
- 右にGOALバッジ。直径72pxの円、背景 `--color-ink`、白文字。旗アイコン、「GOAL」（display 13px）、「あとNこ」（12px / 800）
- 操作不可・影なし。`role="img"` と `aria-label`「ゴールまであとNこ」

完走後:

- 引換券の背景を `--color-yellow` にする。下側の角丸は台紙の角丸に合わせる
- 左に「COMPLETE!」（display 22px、`--color-coral-strong`）と「景品交換所でこの画面を見せてね」（13px / 800）
- 右に「ゴールへ」ボタン。背景 `--color-coral-strong`、白文字、`--border`、`--shadow-md`、高さ52px、旗アイコン付き。押すと影のぶん沈む
- ゴールページへの入口はこのボタンだけとする

### 4-4. 既存コンポーネントの扱い

- `BoardCard` はスタンプ帳画面から外す。ゴールページの道の帯で使う場合は残す
- `GoalMedallion` はスタンプ帳画面では使用せず、参照がなくなれば削除する
- `ProgressBadge` はスタンプ帳画面に置かない。数値の進捗は、景品引換券の「あとNこ」だけで示す
- 円形の `SpotMarker` / `StampSlot` はマップ表示など、場所を示す用途に限定する
- `StampImage` の画像パス、代替画像、スポットごとの傾きは変更しない
- 「スタンプを押す」のような、QR表示を開くための独立したボタンは置かない。QR表示は未押印の押印欄のタップだけで開く

## 5. `design.md` 4-1「電子スタンプ帳」の差し替え内容

共通ヘッダーの下に、上から次の順で配置する。

1. **StampCard（台紙）。** ヘッダーとの間は16px
2. **案内ボタン。** InfoTileを既存どおり3つ横並びにする。台紙との間は24px

現在のタイトル行は削除する。縁取り見出し「スタンプラリー」（英語は「STAMP RALLY」）と、右側の `ProgressBadge` は表示しない。輪の下にあった補足文「紫の番号をタップすると…」も削除し、台紙内の案内文に役目を移す。

台紙内の配置は次を基準とする。

```text
┌──────────────────────────────────────┐
│ STAMP RALLY CARD            岡山大学 │
│ スタンプ台紙          ホームカミングデー │
├──────────────────────────────────────┤
│ 空いている丸をタップして…どの順番でもOK。 │
│                                      │
│    (①)        (②)        (③)        │
│  スポット名   スポット名   スポット名    │
│                                      │
│          (④)        (⑤)             │
│        スポット名   スポット名          │
│                                      │
◗ ✂ - - - - - - - - - - - - - - - - - ◖
│ 景品引換券                   ┌─────┐ │
│ 5つ集めたら、景品交換所で     │GOAL │ │
│ この画面を見せてね           │あと3こ│ │
│                              └─────┘ │
└──────────────────────────────────────┘
```

- 5つの押印欄はすべて同じ大きさにする
- 上段3つ・下段2つの並びは、どの画面幅でも崩さない
- スポット番号は1から5まで表示するが、順番を示す矢印や道は置かない

## 7. レスポンシブとアクセシビリティ

- 基準画面は幅360〜430pxとし、幅320pxでも横スクロールや表示の見切れが起きないようにする
- 台紙の影8px、左右の切り欠き、はみ出した番号バッジとスタンプ画像を含む全状態で、`document.documentElement.scrollWidth` がビューポート幅を超えないようにする
- 横幅が狭い場合は、列間隔（10→6px）、列幅（100→92px）、円の直径（84→76px）の順に小さくする。円は72px未満にしない
- 高さが不足する端末では縦スクロールを許可し、台紙を画面上下で切り取らない
- スポット名は12px未満へ縮小せず、2行までの折り返しを許す
- 英語表示でも5つの押印欄の大きさを変えない
- 装飾（切り欠き、はさみ、下絵、かすれの点）は読み上げ対象から外す
- 未押印欄だけをフォーカス可能にし、押印済み欄は状態を読み上げられるようにする
- 色だけで未押印・押印済み・完走を区別しない。未押印は「ここにスタンプ」の文言、押印済みはスタンプ画像、完走は「COMPLETE!」の文言を併用する
- `prefers-reduced-motion: reduce` では既存どおり押下と押印演出の動きを止める

## 8. 確認項目の追加

`/dev/gallery` とスクリーンショットで次を確認する。

- 押印0個: 5つすべてが「ここにスタンプ」の空欄で、上段3・下段2の構成が一目で分かる
- 押印2個: 押印済みスタンプと未押印欄の違いが、色に依存せず分かる
- 押印5個: 5つのスタンプが台紙内に収まり、景品引換券が黄色になって「ゴールへ」が出る
- 320px、360px、390px、430pxの各幅で、下段2つが上段と重ならず、横スクロールと見切れが発生しない
- 影、切り欠き、番号バッジ、スタンプ画像まで含め、すべての装飾が画面内へ収まる
- スタンプ帳画面に「スタンプラリー」／「STAMP RALLY」の見出し、「0/5」形式の進捗カウンター、QR表示を開く独立したボタン、円形の道・地面・木が残っていない
- 日本語と英語の両方で、見出し、案内文、スポット名、引換券の文言がはみ出さない
- キーボード操作で未押印欄だけを順に選択でき、フォーカスリングが見える
- 5つの各押印欄からQR表示を開き、QRの値と表示寸法が同じである

既存のスクリーンショット対象「スタンプ帳（押印0・2・5個）」は維持し、すべて台紙型で撮影し直す。
