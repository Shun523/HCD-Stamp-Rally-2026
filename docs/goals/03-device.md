# ゴール3：スタンプ機

docs/spec.md の6章に従い、device/ にスタンプ機制御ソフトを Python で新規に実装する。液晶の初期化などは reference/qr_camera_lcs.py を参考にしてよい。

## 完了条件

単体テストがすべて通ること。

- 6-2 のカメラ設定（640×480、15fps、3フレームに1回解析）と液晶表示（中央を正方形に切り抜き、180度回転、QR検出時に緑枠）を実装する
- QR のデコードは OpenCV の QRCodeDetector を使う
- 送信はカメラ処理と別のワーカースレッドで行い、同時送信は1件まで、同一QRの再送は3秒後から
- HTTP タイムアウトは5秒
- 送信結果を 6-7 の5分類で判定し、分類ごとの液晶表示とキュー処理を行う
- キューはファイルに永続化され、再起動後も再送される。同じトークンは1件にまとめる。10月31日中は16:00までのキューを再送し、11月1日0:00（日本時間）に全件削除する。再送結果の扱いは 6-7 のとおり
- 30秒ごとのハートビートに未送信キュー件数を含める
- 押印成功時、スポットIDに対応する240×240のスタンプ画像を、落ちて着地する演出（6-2）とともに3秒表示する。5スポット分を起動時に全件読み込む
- 液晶の日英表示に日本語フォントを使う
- カメラと液晶はインターフェースで分離し、Pi 以外の環境ではダミー実装で起動できる
- 分類・キュー・再送・ハートビートを、HTTP をモックした単体テストで確認している
- 起動時と起動中の双方で、日本時間の11月1日0:00にキューが空になることを時刻注入した単体テストで確認している
- 設定（サーバーURL、APIキー、機体ID、スポットID）は設定ファイルから読む
- systemd の unit ファイルを用意し、異常終了時に自動再起動する
- Ctrl+C で、送信中の処理を終えてからカメラを止め、液晶を黒にして終了する
