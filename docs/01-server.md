# ゴール1：サーバー

docs/spec.md の2章・5章・8章・9章に従い、shared/ と server/ にバックエンドを実装する。

## 完了条件

すべて自動テストで確認し、テスト・lint・型チェックが全て通ること。

- 8章のテーブルを Drizzle で定義し、マイグレーションで作成できる
- 9章のエンドポイントがすべて動く
- 初回アクセスでセッションを発行し、Cookie は HttpOnly・Secure・SameSite=Lax、有効期限は2026年11月30日
- 押印トークンはセッションIDとは別の推測不能な乱数で、有効期限は2026年10月31日16:00
- 新規押印で 200 stamped、同じスポットの2回目は 200 already で、記録は1件だけ
- 不正トークンで 404 invalid_token、APIキー不正で 401
- スマホの ACK が無くても3秒で 200 stamped が返り、記録は残る
- SSE 接続中のクライアントに、イベントID付きの stamped イベントが届き、15秒ごとに ping が送られる。同一セッションの複数接続すべてに届く
- device_stamped_at 付きの押印では、その時刻が押印時刻として記録される
- ハートビートが90秒途絶えた機体が /api/admin/devices で「断」になり、未送信キュー件数が表示される
- /api/health は DB への疎通確認を含む
- stamps に session_id と spot_id の一意制約を張り、二重押印を DB 側でも防ぐ
- 全テーブルで RLS を有効にし、ポリシーは置かない
- 押印記録はプロセスを再起動しても残る（テストはローカルの PostgreSQL で行う）
- 管理 API は共有パスワードで保護する
